## 执行内容
1. 对 39 个场景逐个标明数据来源：真实产品 UI（真实文件/会话，须是隔离数据）/fixture 模拟/空页面/缺上游对照/截图缺失；提取有可验证的对照字段如 width/DPI/theme/collapsed state/焦点。
2. 差异分功能断裂、焦点键盘/可访问性、内容溢出、样式 token/空间、仅微小装饰 5 类；优先列出**真实可复现**且影响用户使用的缺口，避免拿快照数量造“通过率”。

1. 39/39 场景逐行注明真 UI/fixture/空页/缺证据及理由，汇总数精确。
2. 主要差异按可见证据/路径/功能影响分类，至少列三个可操作的差距或证明无证据可下结论；不能只有审美意见。
3. 给出不重叠源码边界的下一批 UI 开发卡建议，避免 T24/T64/T65/T30 和当前 shared Store。
4. 没有修改任何产品源码、旧夹具/快照；只读无需变异 N/A，真实用户旅程未取得证据不报 U1。

# 派发任务卡：<任务 ID>｜<标题>

你是 Mcode 项目的独立执行对话，只负责 `tasks/<任务文件名>.md` 中这一张已批准任务卡，不得自行扩大范围或接管其他任务。

必须按以下顺序执行：
1. 完整读取任务卡、`tasks/README.md`、`audit-ledgers/README.md`，以及任务卡列出的相关台账/文档。
2. 读取 `Required Skills` 列出的每个 Skill 的 `SKILL.md`，按指定用途使用；Skill 不覆盖任务边界或验收标准。
3. 检查 Git HEAD、完整工作区状态、前置依赖和独占可写文件；保留所有他人的未提交修改。禁止 reset、clean、整文件回滚或未经授权的路径写入。
4. 按任务卡先验证旧红，再实施最小修改，再验证新绿；安全关键路径执行变异验证。
5. 只运行与改动相关的测试，并明确区分静态证据、隔离 E1 与真实 Electron U1。
6. 仅暂存自己负责的文件；检查 staged path list 和 diff；不得把他人修改带进提交。
7. 按任务卡回写结果、测试输出、提交 SHA、未达判据和剩余风险。

最终回复只列：任务编号与标题；实现/结果回写提交 SHA；验收判据是否全部达成（未达则逐条列出）。若任务卡与当前代码或台账冲突，先停下并报告证据，不猜测。

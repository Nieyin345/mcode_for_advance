## 背景：总控已独立复现，这不是推测

A 在 T70 独立复核时发现，总控复现：

```
T62 空柱子(坏):  ratio=0.850  → 不报     （卡片 452 高，文字底距卡底 300px）
同内容 300 高(好): ratio=0.639 → 报       （文字填满，底距卡底 28px）
```

**同一个内容，卡片拉高（坏）不报、收紧（好）反而报。**

## 根因（读代码，`deckPatternCheck.ts:203-218`）

```ts
const content = els.filter((e) => !isFullBleed(e));
const bottom = Math.max(...content.map((e) => (e.y ?? 0) + (e.h ?? 0)));
const ratio = bottom / CANVAS_H;
```

**卡片形状自己就是元素。** 卡片越高 → 底边越靠下 → `ratio` 越大 → **把卡片拉高、文字只占上半截这种正是要抓的丑法，反而判为合格。**

这正好是 T62 的原话：

> 卡片被我加高到 452px 后，**每张卡内部下半截是空的**（文字只占卡片上部约 1/3）。视觉上像「三根空柱子」。

**T65 交付时 22/22 全绿，因为它自己的负控夹具是「内容只到 60%」——那是「整页只用上半部分」，不是「卡片内下半截空着」。两种丑法不一样。**

## 任务

### 第一步：先对齐数字（**这一步不能跳**）

A 与 E 的数字对不上：

| | 分母 | 空柱子 | 好的 |
|---|---|---|---|
| E（T65 回写区） | 卡片高？ | 0.787 | 0.535 |
| A（T70 复核） | 卡片高？ | 0.893 | 0.642 |
| **总控复现** | **卡片高** | **0.664**（300/452） | **0.093**（28/300） |

**先搞清 E 和 A 各自的分母是什么、为什么不同。** 可能的差异：

- E 的「文字占卡片比例」用的是**文字面积 / 卡片面积**（二维），A 和总控用的是**底边距 / 卡片高**（一维）；
- 或者是「文字顶起算」vs「文字底算」。

**把三种算法各写出来、在同一组夹具上跑，确认哪个能分开好坏。** 这个对齐结果要写进回写区——**因为改判据时选错分母，会把方向再判反一次**。

### 第二步：改成按容器算

A 的建议（总控认可）：

> 判据应改为按容器算：量「**卡内文字底边距卡底的留白 / 卡片高**」。

```
T62 终版（坏）  → 0.664（总控算）   
同内容 300 高（好）→ 0.093（总控算）
```

**能分开，而且现在的判据把两者判反。**

实现要求：

1. **识别「容器」**：页面上有 `shape`（圆角矩形/矩形）且它下面有 `text` 时，那个 text 属于该 shape；
2. **对每个容器算** `(cardBottom - textBottom) / cardHeight`；
3. **阈值方向反过来**：这个值**越大越空**（不是越小）；
4. **保留整页级的判据**（「整页只用上半部分」）——**两种丑法都要抓**，不能用一个替掉另一个；
5. **没有容器的页**（纯文字页、纯图页）走整页级判据。

### 第三步：正控 + 负控（**两种丑法各一对**）

| 丑法 | 负控（必须报） | 正控（必须不报） |
|---|---|---|
| **卡片内下半截空**（T62 空柱子） | 卡片 452 高、文字只到上部 → **必须报** | 卡片 300 高、文字填满 → **必须不报** |
| **整页只用上半部分** | 内容底边 60% → 必须报 | 铺满 → 必须不报 |

**关键**：第一对必须在**旧判据下是反的**——即旧判据下坏的不报、好的报。这条要写进回写区，作为「这个 bug 真实存在」的证据。

### 第四步：变异

- 把新判据的**阈值方向改回**（`>` 改 `<`）→ 两个负控必须红 → `cmp` 还原；
- 把容器识别去掉（所有 text 都算整页）→ 「卡片内空」负控必须红 → 还原。

### 第五步（新增，A 的 T70 复核数据）：KPI 边界与 error 降级

**A 实测 KPI 页极易踩线**（T62 真实 KPI 页 ratio 0.8333，余量 3.3pt）：

| 卡片减 | ratio | 结果 |
|---|---|---|
| 24px | 80.0% | 不报（恰好压线） |
| **32px（约一个行高）** | **78.9%** | ❌ **误报** |

**这说明「整页级判据」的 80% 线本身就在真实设计的高频区。** 改判据时：

- 按容器算的新判据要与整页级判据**并存**，不是替代；
- 整页级那条的 80% **保留**（T69 已校准，它抓的是另一种丑法），但**KPI 那类页面会踩线**这件事要写进注释。

**同时：`accent-bar.*` 与 `cover.flat` 从 `error` 降为 `warning`。**

A 的理由（总控认可）：**7 条里只有 `palette.rainbow` 的阈值有规范出处**（"Never more than the two accents"），其余 6 条全是拍的 —— **而恰好两条 error 的阈值也是拍的**。拍的阈值不该升成 error。

（`palette.rainbow` 保持 error：它的阈值来自规范原文。）

## 结果回写（2026-10-23，E 会话）

### 一、第一步：数字对齐（改代码之前做的）

**结论：总控的判断成立，但根因不是「分母不同」，是「我用错了样本」。**

**实测（照描述造真「空柱子」：卡片 452 高、文字只到上部）：**

```
                        整页底边    卡底留白
空柱子(真)                0.872       0.580   ← 整页判据判「合格」
好(同样卡高、文字填满)      0.872       0.062
```

**整页级在两页上给出**完全相同**的 0.872** —— 一个数都分不开。**「卡片形状自己就是元素」这个根因准确。**

**三组数字为什么不同：**

| 来源 | 数值 | 实际量的是什么 |
|---|---|---|
| 我 T65 回写区 | 0.787 / 0.535 | **旧版 `bad02`（卡片 300 高）** —— 那是「卡片变矮」，不是空柱子 |
| A 的 T70 复核 | 0.893 / 0.642 | 文字底 / 卡底（越大越满） |
| 总控复现 | 0.664 / 0.093 | 留白 / 卡高（越大越空） |

**三种分母我都算了**（真样本上）：`① 留白/卡高=0.580`、`② 文字底/卡底=0.583`、`③ (文字底-卡顶)/卡高=0.420`，好的分别是 `0.062 / 0.955 / 0.938`。**三种都能分开好坏 —— 算法不是瓶颈，样本才是。**

**最该记的**：T65 交付时我说「用 T62 真实 deck 校准」，但那个最关键的坏样本 `bad02` 是**我自己造的、而且造错了**。用一个标签错误的样本去证明判据有效 —— 这比「判据判反」严重，因为判据确实在自己的目标上工作。

### 二、改了什么

**1. 新增容器级判据 `layout.card-whitespace`**

量「卡片内文字底边到卡底的留白 / 卡片高」，取最空的一张卡。**方向：越大越空**（与整页级相反）。

**2. 整页级判据保留**

它抓「内容只占上半页」是有效的，两条并存、互不替代（有断言证明，见下）。

**3. `accent-bar.vertical` / `accent-bar.top` / `cover.flat` 降为 `warning`**

A 查了 7 条判据的出处：**只有 `palette.rainbow` 有规范原文**（"Never more than the two accents"），其余 6 条是经验值。**拍的阈值不该以 error 身份打断模型。** `palette.rainbow` 保持 `error`。

**4. 整页级注释补上 KPI 边界事实**

T62 的 KPI 页是 0.8333，卡片减 32px（约一个行高）就掉到 78.9% 被误报 —— **80% 落在真实设计的高频区，这是已知的、可接受的误报面**，改它是调参不是修 bug。

### 三、关于 `0.45` 的注释原文（卡上要求交原文）

```ts
/**
 * ## ⚠️ 样本量 = 2
 *
 * 一个空柱子（0.580）、一个填满（0.062）。`0.45` 是**这两个数的区间中点**，
 * 不是校准值 —— 它离两边各有 0.13 / 0.39 的余量，足够区分这两个已知形态，
 * 但**没有任何证据说明 0.45 对其它设计是对的**。
 *
 * T69 的教训在这里同样成立：不要在少量样本上精调。等真实 deck 攒到 10 页以上
 * （或 T63 扩出更多夹具）再回来校准。
 */
export const CARD_WHITESPACE_REFERENCE_LINE = 0.45;
```

### 四、两对正控负控（两种丑法各一对）

| 丑法 | 正控 | 负控 |
|---|---|---|
| **卡片内下半截空着** | 卡片填满 → 不报 | 文字只到 366/卡底 628 → **报** |
| **内容只占上半页** | 铺满的页 → 不报 | 内容只到 60% → **报** |

**外加两条「互不替代」的证据：**

```
ok  ★ 空柱子页的整页判据不报（证明它抓不到这种丑法）
ok  ★ 只占上半页的页没有卡片内文字 → 容器级判据不报
```

再加三条措辞断言（参考线 / 不含硬词 / 允许有意留白），与 T72 那条同纪律。

### 五、变异结果

```
drop-card-whitespace:  rc=1 red=1    FAIL ★ 负控：卡片内下半截空着 → 报出来
threshold-to-zero:     rc=1 red=1    FAIL ★ 正控：卡片填满 → 卡底留白判据不报
drop-page-whitespace:  rc=1 red=2    FAIL ★ 负控：内容只到 60% 被报 / closing 只到 30% 被报
RESTORED: byte-identical
FINAL: rc=0
```

**第三个变异同时证明了「两条判据互不替代」**：撤掉整页级，它自己的两条负控红，而容器级的新判据不受影响。

⚠️ `threshold-to-zero` 红的是**正控**（好页被误报），不是负控 —— 因为阈值改成 0 等于「永远报」。这也是判别力的证据，只是方向不同，如实记下。

# MCP 文本工具修复与合并发布（2026-10-03）

用户授权：合并上一轮文档/代码审查修复与本轮 MCP 修复，提交并发布正式补丁版本。远端最新正式版本为 v0.1.56，本轮采用 v0.1.57；不修改其他本地标签。

## 本轮修复

- 新增 `agentTextFiles.ts`，统一同路径文本修改串行控制；编辑通过临时文件替换，写入前校验原始内容仍然一致。可选 `expected_sha256` 拒绝过时编辑。这是本进程串行控制与乐观冲突检查，不是能锁住任意外部编辑器的 OS 事务。
- 单文件文本读取改为有预算的 UTF-8 正文分页；原始内容保留 BOM、CRLF 和 Unicode。无效 UTF-8 明确拒绝，避免替换字符造成静默损坏。
- `column_offset` 与续读游标使用 UTF-16 code unit；模型使用返回值续读，不自行猜字符偏移。读取计算全文件 SHA-256，大文件仍流式处理、内存中仅保留有预算的正文；哈希需要扫描全文件，并非只读取请求片段的 I/O 成本。
- `max_chars` 约束原始正文，默认 30000，最高 60000；行号/说明与结构化元数据另计。批量读取继续是预览，完整读取使用单文件分页。
- 修复 CRLF 替换适配；搜索返回实际命中窗口，并用 `line_truncated` 区分单行预览截断与结果条数截断。
- 校准共享提示词中的 PDF 容器、Windows helper 与转录质量描述。握手版本来自实际 package.json，新增工具契约标识；不再硬编码 1.0.0。
- 公网变更仅为说明文字纠正，不改变权限、工具暴露清单或隧道策略。

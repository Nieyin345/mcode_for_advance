# Mcode v0.1.61

本版合并自 v0.1.60 以来累计的审查修复（第三十二批之前的二十余批）与本轮的两项能力调整。
**功能面全部保留，但发布形态有一处改变**——见「兼容性提醒」。

## 能力调整

### 可选内容不再随安装包内置（行为变更）

原先随应用发布的**五个对话模式**（文献检索 / 精读 / 写作 / 评审 / 代码）、**两条自动化**
（文献导入 / 文件到位后在线转 Markdown）以及**自定义 UI 的开箱菜单预置**，从安装包中**摘出**，
改为仓库里的独立预置文件，由用户在「设置 → 工作流」里按需导入。

- **老用户升级不受影响**：已播种/自建/导入的工作流与自动化、以及你配好的扩展菜单，全部原样保留，
  本机行为与升级前一致。只有**全新安装**才是空的（默认只剩一个「默认」模式）。
- 插件的 skills / MCP / hooks 投递链路不变。

### 扩展面板可调用任意主进程方法

「设置 → 扩展」里的自定义面板新增 `mcode.api.call(method, input)`，可调用 Mcode 的**任意一个**
主进程方法（与界面点按钮、与 AI 的 `app_api_call` 走同一段代码），复用同一套权限闸：只读方法直接
返回，有副作用的方法弹确认框，高风险操作每次确认，密钥类一律拒绝。

### 改名：「自定义 UI」→「扩展」

设置页里这个面板的名字从「自定义 UI」改为「扩展」（英文 Extensions）——避开与既有的「插件」面板
（管 skills / MCP / hooks）重名。**只改用户可见的字**：设置键、代码标识符、RPC 通道名一律未动，
已配好的菜单与面板一个字节不变。

## 修复（覆盖二十余批）

本版包含数百处底层修复，主体是四类长期存在的缺陷，逐条经变异验证（撤掉修复能让断言真的变红）：

- **静默失败收口**：失败后只打日志、界面毫无反应的地方（点按钮没反应、落盘失败静默回弹、回执没
  送到而卡片已消失、一个仓库列不出来就整块伪装成「暂无工作树」……）改为如实报出来。
- **同一规则两份实现、然后漂开**：把散落的重复判据收敛到共享实现（跨引擎能力声明、四支映射、
  扩展动作选项、送图上限等）。
- **跨端 / 跨引擎一致性**：手机壳与桌面在设置白名单、git 操作、行操作失败提示上的行为对齐。
- **OS 英文原文与绝对路径外泄**：文件、记忆、技能、MCP 等通路的错误在失败时把 `ENOENT: …,
  open 'C:\Users\…'` 这类系统原文漏进中文界面与 AI 工具，统一翻成中文（保留原文仅进日志）。

另有若干竞态修复（轮询 / 切换项目 / 切换工作树的旧回包盖掉新状态）、资源泄漏（模块级 Map/Set
只涨不落、清理函数写了没人调）与本地化补齐。

## 性能

- 渲染端流式冲刷从 O(分段数 × 消息数) 降到每帧 O(消息数)。
- 开发与 CI 提速：typecheck 增量缓存、Tailwind 编译缓存、无头回归全量并行（约 15 分钟 → 约 5 分半）。

## 兼容性提醒

**升级后请重启 Mcode，并让外部 MCP 客户端重新连接、重新获取 `tools/list`。** 仅发布 Release
不会自动更新仍在运行的旧 MCP 进程。

## 边界

- 应用**未做代码签名**：macOS 首次运行需右键 → 打开；Windows 会显示 SmartScreen 提示。
- 不改变公网 MCP 的授权、免审批或隧道策略；命令的有限静态检查不是强沙箱。
- 转录、DOI 下载与学术元数据处理仍由配置的自动化负责，核心不恢复直接转录或本地降级。
- 本版不宣称已完成全部历史问题、真实模型 / 在线服务验收或整块未实现的功能。监控崩溃对账、
  丢失审批卡恢复、自动化的「错过定时补跑」等仍见 `docs/功能性问题审查记录.md`。

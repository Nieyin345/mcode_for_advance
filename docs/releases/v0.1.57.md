# Mcode v0.1.57

本版合并此前尚未发布的审查修复与 MCP 文本工具修复。

## MCP 工具与提示词

- 同一真实路径的文本编辑在工具宿主之间串行，避免两个调用都成功却丢失其中一次修改。
- `agent_read_file` 新增有预算的无损正文分页，支持长行、Unicode、CRLF 和 BOM；返回内容哈希及续读游标。可通过 `expected_sha256` 拒绝过时续读或编辑。
- 单文件读取默认正文预算 30,000 字符，避免把整个大文件一次塞入模型上下文。带行号的预览与可原样处理的 `structuredContent.content` 明确区分。
- 修复单行替换为多行文本时的 CRLF 混用；失败的批量编辑不部分落盘，失败不会卡住后续编辑。
- 长行搜索返回命中附近内容，并单独说明行预览是否截断。
- 发布此前已有的批量 `edits`、搜索字面量/大小写/隐藏文件参数，以及失败标记修复。
- MCP 握手报告实际应用版本和工具契约标识；校准平台、文档格式和转录质量提示，不再把 PDF 当 ZIP 或把某个 helper 的历史故障当永久平台事实。

## 会话与工作流

- 修复 Codex 停止竞态、等待者悬挂和早到子线程通知串入主对话。
- 修复安全纯节点的中断续跑、桌面历史运行入口，以及失败时已返回的部分产物丢失。
- 最后一个后台子代理结束后可唤醒会话队列，同时保留主回合与其他后台任务的忙碌保护。
- 合入此前的错误反馈、通知本地化及本地审批缓存修复。

## 兼容性提醒

**命令节点不再允许在 shell 正文中插入动态模板变量。** 请使用固定命令，从既有 JSON 标准输入读取 `userInput`、`trigger` 和上游数据。旧写法会收到迁移提示；本版不会自动改写用户自定义工作流。

升级安装后，请重启 Mcode 并让 MCP 客户端重新连接、重新获取 `tools/list`。仅发布 Release 不会自动更新仍在运行的旧 MCP 进程。

## 边界

- 不改变公网 MCP 的授权、免审批或隧道策略；命令的有限静态检查不是强沙箱。
- 转录、DOI 下载和学术元数据处理仍由配置的自动化负责，核心不恢复直接转录或本地降级。
- 本版不宣称已完成全部历史问题、真实模型/在线服务验收或整块未实现功能。监控崩溃对账、丢失审批卡恢复等仍见审查文档。
- Windows 发布新增解包资源和隔离运行时校验；macOS 仍采用项目原有的签名方式，首次运行可能需要系统确认。

# 技能市场按需下载

GitHub 技能集合不再通过 `git clone` / 仓库 ZIP 来浏览。Anthropic、OpenAI 两个默认来源与自定义公开 GitHub 来源使用同一条索引路径。

## 加载与安装

- 添加/刷新：通过 GitHub API 获取 commit SHA（SHA 媒体类型，不取 commit diff）与递归文件目录，再并发读取每个技能的 `SKILL.md` 头部，最多保留 8 KiB 用于名称/简介。不会请求脚本、图片、模型、数据集等文件内容。
- 本地只保存 JSON 索引，包括文件路径、大小、Git blob SHA、技能简介。`cloned` 是旧 IPC 字段名，现表示索引/旧缓存已就绪，不代表做过 clone。
- 列表/搜索读取本地索引，不联网。刷新发现 commit 未变时复用目录和简介，只查询版本。
- 点击安装：固定使用索引记录的 commit，仅下载所选技能目录内的文件，校验长度及 Git blob SHA；完整下载后才移入总库。不会安装/启用其他技能，同名项直接跳过且不产生下载请求。
- 不自动推断或下载技能目录外的共享依赖；原来的本地目录安装仍按目录复制。脚本中的软件依赖仍需按技能说明另行配置，不执行仓库代码。

## 缓存兼容

已有的整仓缓存可以继续离线列出、安装选中的技能。第一次成功刷新后，以 JSON 索引替换该来源的旧仓库缓存；失败保留旧缓存。已安装技能不受刷新/删除来源影响。本轮开发验证不修改用户实际缓存、技能库或数据库。

## 限制与失败行为

- 在线索引支持公开 GitHub 仓库、`owner/repo`、GitHub HTTPS / SSH 地址，以及明确的 `/tree/分支`。带斜杠的分支需 URL 编码；不接受有歧义的子目录地址。
- 非 GitHub Git 服务、私有仓库请使用已准备好的本地目录。不会自动发现密钥/令牌，也不会在 API 出错时静默回退到 clone/整仓下载。
- GitHub 限流、拒绝访问、缺失文件和超时会报错；没有目录数据时不假装成功。目录 API 返回 truncated 时保留旧索引。
- 桌面请求使用 Electron 系统网络栈，遵循系统代理/证书信任，不关闭 TLS 校验，不携带 GitHub 登录 Cookie。
- 每请求 30 秒、每次索引/单技能下载操作 5 分钟；最多 6 个并发请求。索引最多 2000 个技能、100000 条目录条目，目录响应 12 MiB。
- 单个技能最多 2000 文件、合计 128 MiB、单文件 32 MiB，超出时明确建议本地目录。路径穿越、Windows 保留名/别名、大小写冲突、符号链接、submodule 和 LFS 指针拒绝安装，不追随到其他目录或安装不完整的占位内容。
- 只读取 SKILL.md 头部不等于零下载；HTTP 缓冲可能提前接收更多字节，达到头部上限即取消正文读取。与下载全仓全部技能资源是不同的行为。

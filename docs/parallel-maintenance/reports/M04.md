## 发现与修复

- **BUG-M04-01（P1，plan 模式绕过逐次审批）**：`EnterPlanMode` 会同步设置闭包中的 `planMode.active`，但审批判定只看 UI/IPC 回传的 `ctx.getPermissionMode()` 与 session `alwaysAllowed`。权限模式更新存在异步延迟；例如当前值仍为 `acceptEdits` 时，plan 内的 `write/edit` 会被自动批准；已保存的 always-allow 也可能跳过 plan 内审批。与工具描述的“plan 中每个修改操作都需审批”不符。
- 修复：抽出 `piToolApproval.ts` 统一决策。只读内置工具仍可免审批；plan 活跃时优先于陈旧 permission mode、`bypassPermissions` 和 always-allow，所有变更类工具都转到 host approval；离开 plan 后原 permission mode 与 always-allow 语义保留。
- 新增 `maint-m04-smoke` 7 项策略回归，覆盖陈旧 `acceptEdits`、always-allow、bypass、plan 内只读放行及 plan 外既有行为。`mcodeExtension` 的实际 `tool_call` guard 调用同一 helper。

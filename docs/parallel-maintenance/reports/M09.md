## 发现与修复
### BUG-M09-01（P1）：LSP/Monaco 文件 URI 未编码，文件身份可能被误解
两端 filePathToUri 都直接拼接文件路径。`a#b.ts` 变成 fragment，POSIX `a?b.ts` 变成 query；字面 `a%23b.ts` 在逆转换时变为 `a#b.ts`。空格/中文也未生成规范编码 URI，影响严格字符串匹配。新测试以 Node URL 标准库为独立参考，并检查 hash/search 为空和路径还原；普通路径为通过控制。
实际修改：`main/lsp/LspManager.ts` 与 `renderer/lib/lspProviders.ts` 的现有转换 helper 对路径使用 encodeURI，再显式编码 #/?，同时正确转义字面百分号。保留现有斜杠/盘符处理、函数签名与既有调用点。main 和 renderer 对同一输入仍一致；不把 Node 模块带进 renderer。

### BUG-M09-02（P2）：目录 URI 追加重复末尾斜杠
`dirPathToUri('/tmp/project/')` 原来得到 `file:///tmp/project//`，POSIX 根得到 `file:////`。现在仅在 URI 未以斜杠结尾时追加；不改变没有尾斜杠的目录行为。

生产差异共2文件，8行新增/3行删除；没有性能优化声明，没有改现有测试/公共入口/组件/保存逻辑。

## 发现与实际修复

### BUG-M12-01 · P1 本地文件名的 #/? 被当作 URL 片段/查询

- 根因：encodeURI 保留 `#` 和 `?`，但输入是文件路径而不是带查询或片段的 URL。
- 实际反例：`C:/docs/report#draft.html` 输出带 fragment；`/tmp/report?draft.html` 输出带 query；独占临时目录里真实存在的 `中文#draft%23.html` 转回文件路径后被截断到 `中文`，无法指向原文件。
- 最小修复：`browserUrl.ts` 在 encodeURI 后将字面 #/? 编成 `%23`/`%3F`。保留盘符、分隔符、原百分号编码和中文空格行为；不解码输入、不引入 Node API 到 renderer、不修改网页 URL 的原有 query/fragment。
- 消费者：BrowserPanel 地址栏以及只读确认的 FileTree 调用共用此辅助函数；FileTree 归 M07，本任务未修改。

### BUG-M12-02 · P2 跨越视口原点的 stage 把未测量 portal 误判为遮挡

- 已有代码契约：OCCLUDER_UNMEASURED 是不可见 portal 的占位符，应从不重叠；null 才代表未知几何，需要保守隐藏。
- 复现：stage 为 left/top=-10、right/bottom=300，登记零面积 sentinel；旧比较的四个不等式全为 true，返回应隐藏，预期 false。
- 最小修复：`browserOcclusion.ts` 显式跳过 sentinel；不改 null/无 stage/空 registry 的保守策略，不跳过另一真实重叠弹层。
- 这是几何判定的有效行为复现，不宣称已经用真实 Electron 窗口拍摄到闪烁或测量性能收益。

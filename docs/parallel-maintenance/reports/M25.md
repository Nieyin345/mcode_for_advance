## 发现与修复

- **BUG-M25-01（P2，错误不可见 + unhandled rejection）**：`RuntimesPanel` 的 `doInstall`/`doRemove`/`doInstallLocal` 只有 try/finally 没有 catch，且 `doInstallLocal` 的 `api.pickFolder()` 在 try 外——`api.runtimes.*` 一旦 reject（主进程异常/通道断开/入参校验失败），用户点按钮界面毫无反应，rejection 落到 window 级。同页 ToolchainSection 一直是 catch → actionError。修复＝三个动作补 catch → `setActionError(t(installFailed/removeFailed, {error}))`，pickFolder 移入守卫；复用现有词条，未动共享词典。
- **BUG-M25-02（P2，同类）**：`DataRootPanel.move()` 同样只有 try/finally；`moveDataRoot` reject 时「迁移失败」完全不可见，`pickFolder` 在 try 外。修复＝pickFolder/ moveDataRoot 均补 catch → setError(err.message)，`setError(null)` 提前到入口。
- **BUG-M25-03（P2，输入被 clamp 抢改）**：`GeneralPanel` 长文本折叠阈值输入框每个 keystroke 直接 `setPasteTagThresholdChars(Number(v))`，store 立即 clamp 回写受控 value——清空变 50、想输 300 键入 "3" 即被改成 50（光标下换值），且每个中间态都写一次 SQLite。修复＝本地草稿 state：合法且在界内的值即时生效（保留原实时体验），失焦时 clamp 提交、空/不可解析草稿回退到已存值不写库。
- **BUG-M25-04（P3，可访问性）**：`RuntimesPanel` 内核行的两个展开开关（chevron 与摘要行按钮）无 `aria-expanded`，读屏器无法得知展开态。修复＝两处补 `aria-expanded={expanded}`。
- 实际修改文件：`RuntimesPanel.tsx`（+22/−2）、`DataRootPanel.tsx`（+15/−3）、`GeneralPanel.tsx`（+37/−2）。无性能优化项（未发现有量化收益的候选）。

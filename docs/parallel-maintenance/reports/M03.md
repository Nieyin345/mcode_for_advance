## 发现与修复

- **BUG-M03-01（P1，settle 时序/审批通道风险）**：原 guard 仅在 `lastResultAt < lastAgentActivityAt` 时阻止 settle。两事件落在同一毫秒时比较相等，代码错误地允许释放 stdin hold；在后台任务恢复主循环的窗口里，后续询问/审批可能遇到已关闭的 stdin。
- 红灯：新测试固定 `Date.now()`，先发空 `background_tasks_changed`，再发同毫秒 success result；修复前在 1.5 秒 grace 后观察到 release（目标断言失败）。另有严格较新时间戳的对照断言通过。
- 最小修复：`apps/desktop/src/main/providers/claude-sdk/SdkMessageAdapter.ts` 将时间判定改为 `lastResultAt <= lastAgentActivityAt` 时继续等待；真正更晚的 result 仍可 settle。

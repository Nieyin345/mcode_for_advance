## 发现与修复
- **BUG-M18-01（P0，递归删除越界）：“从本地路径安装内核”把 package.json 里的 version 直接当成目录名。**
  - 根因：`installRuntimeFromLocalPath` 从用户选择的目录或 .tgz 读取 `package.json.version`，交给 `finalizeInstall`，后者执行 `rmSync(join(root, agent, version), { recursive: true })` 再 rename。
  - 复现与影响（红灯均实测）：
    - `"../pi"`：安装“成功”，**pi 内核被整个删掉**，替换成 claude 的载荷。
    - `".."`：删掉整个受管运行时根目录，所有内核都没了，安装随后以 ENOENT 失败。
    - `"../../.."`：**删到应用数据目录之外**。测试中沙箱外层的哨兵文件被删；真实环境下对应 userData 的上一级目录。
    - `"."`：删掉该 agent 已安装的内核。
  - 修复（`runtimeInstaller.ts`，+13/−1）：`finalizeInstall` 在任何删除之前校验版本号必须是单个安全目录名（`^[A-Za-z0-9][A-Za-z0-9._+-]{0,127}$`），并且目标的父目录必须正好是 `<root>/<agent>`，否则抛出明确错误。staging 由原有的 finally 清理。registry 路径的钉版版本号（如 0.3.258、0.153.4）不受影响。
- **观察，未改**：
  - TinyTeX 的目录名取自 GitHub API 的 `tag_name`，没有做同样的字符校验。它来自固定仓库的 HTTPS API，而且必须匹配资产名，风险低。上游一旦被攻破本身就能投递任意二进制，所以只作加固建议。
  - pandoc 版本已经由正则保证以数字开头、不含斜杠。
- **性能优化**：无，本任务未做性能改动。

## 发现与修复

- **BUG-M35-01 / P1 · 旧请求覆盖新列表或详情**。复现：同一分类/全库/分类总表先后请求，后发先回，旧响应再回时把新缓存盖回旧值；新建分类后旧总表还会把新分类清掉；删分类后在途条目又复活。`ItemLinks` 在 A→B 后 A 的关联晚回也会展示在 B 下。根因是异步结果直接 set，无请求所有权判断。`renderer/stores/libraryStore.ts` 对总表、每分类与全库缓存加请求代际，在新建时失效旧列表，删分类时清过期请求，成功新建时正确置 `loaded`；`components/library/ItemDetail.tsx` 给关联列表加 item/request 守卫和切换清空，两个调用点按 item id 重建，笔记组件亦按 item id 重建。
- **BUG-M35-02 / P2 · 目录子 PDF 的批注保存目标错误**。`FilePreview` 读取 `relPath` 子文件时仍将 `entryPath` 返回的目录根传给 `PdfPreview`；保存会尝试写目录而失败。修复：仅 PDF 分支将受控的当前 `relPath` 拼到条目根，其他文件路径语义不变。注意本修复仅纠正送往保存 API 的目标；“外部打开”仍受下述 M33 接口限制。
- **BUG-M35-03 / P2 · 键盘打不开列表项／看不到关联删除**。`ItemList` 的非空行原来是带 `onClick` 的 div，Tab/Enter 到不了；复选框无标签。改为 checkbox 与独立原生按钮（保留点击激活、选中竖条及状态徽标），加中英文 checkbox 标签和焦点样式。`ItemDetail` 关联删除按钮原先只有 hover 才从透明变可见；加 focus-visible / group-focus-within 可见性及 aria-label。
- **BUG-M35-04 / P1 · 损坏的标注索引在下次保存时不可恢复**。`readHighlights` 读坏 JSON 返回空但保留原件；下一次 `writeHighlights` 原子替换会覆盖坏索引，原始残片无从恢复。`main/library/pdfHighlightsStore.ts` 写前识别无法解析/版本不合/含无效记录的旧索引，以不覆盖的唯一 `.corrupt-<uuid>` 同目录备份后再正常保存；备份失败则拒绝覆盖。有效索引不生成备份，PDF 正文不动。保留旧测试所要求的“坏索引读空、之后仍能保存恢复”的行为。

没有声称性能优化；未做可比较的性能基准。PDF/PPT 等真实大文件的体验仍须桌面手工验收。

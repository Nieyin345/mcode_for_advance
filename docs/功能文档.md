## 一、产品定位与总原则

Mcode 是一个**本地优先的通用 AI 代理桌面工作台**，主要面向**科研（文献、论文写作）和写代码**。
它不自己实现代理能力，而是把成熟的代理引擎接进来，在上面提供：对话、资料库、编辑器/IDE、
工作流与自动化、记忆、手机远程、对外 MCP 等一整套工作环境。

总原则（适用于全部功能）：

| 编号 | 原则 |
|---|---|
| P-01 | **本地优先**：会话、资料库、模版、工作流、记忆都存在本机同一个数据目录里，可以整体迁移。 |
| P-02 | **界面中文为主，同时提供英文**；所有界面文字走 i18n，不硬编码。 |
| P-03 | **出错要让用户看得见**：保存失败、发送失败、创建失败等，必须有提示（toast / 内联错误），不能只进控制台或静默吞掉。 |
| P-04 | **不丢数据**：编辑器、设置、消息落库在并发、切换、重启时都不应丢改动；外部改动与本地改动冲突时要提示而不是覆盖。 |
| P-05 | **密钥不外泄**：API Key、令牌不返回给模型、不出现在日志和远程接口的返回里，界面上一律打码显示。 |
| P-06 | **危险操作每次都要用户批准**（删除/移动文件、执行任意命令、终止进程等），对外暴露的接口里不允许「总是允许」。 |
| P-07 | **提示文字能藏就藏**：界面保持简洁，说明性文字放在可展开的提示里，符合常规软件的使用习惯。 |
| P-08 | 升级不破坏已有数据：老数据（旧会话、旧工作流、旧设置）升级后照常可读可用。 |

## 二、AI 对话

### 引擎与模型

**CHAT-01 三个本地引擎**
- 应当支持 Claude（Claude Agent SDK）、Codex、Pi 三种引擎，开新会话前可选。
- 三个引擎在以下方面行为一致：流式输出、工具调用与审批、子代理、提问（AskUserQuestion）、token 用量与花费显示、中断、结构化输出、轮预算、失败回退。

**CHAT-02 自定义模型（OpenAI 兼容接口）**
- 应当能在设置里添加 OpenAI 兼容接口（地址 + Key + 模型名），给引擎使用。
- Key 只在设置时写入一次，之后界面只显示打码串。

**CHAT-03 网页模型（另一种 API 来源，不是引擎）**
- 应当能通过浏览器扩展桥，把网页版大模型当作一个 API 来源使用。
- 它是「另一种 API」，挂在引擎下面用，**不是第四个引擎**。
- 至少支持 DeepSeek 网页版和 ChatGPT 网页版两个站点。

**CHAT-04 引擎安装与健康检查**
- 设置 →「引擎/运行时」能看到各引擎是否可用、版本，必要时一键安装或给出明确的修复提示。

### 对话流程

**CHAT-05 流式对话**
- 回复实时流式显示（文本、思考过程、工具调用、工具结果）。
- 长对话（数百条消息）流式输出时界面不卡顿。

**CHAT-06 工具审批**
- 工具调用需要批准时显示审批卡：允许 / 总是允许 / 拒绝；桌面和手机任一端回答都生效，另一端同步消失。
- 回答后卡片消失、输入框恢复，不会出现输入框被锁死的情况。

**CHAT-07 计划模式**
- 能先让模型出方案，用户批准（可编辑方案、可附反馈）后再动手。

**CHAT-08 提问**
- 模型向用户提问时显示问题卡，可选择/填写答案或关闭；回答后同一轮继续。

**CHAT-09 中断与排队**
- 运行中可以停止当前回合。
- 运行中发的消息进入队列，回合结束后依次发出；队列可查看、可清空。
- 运行中按 Ctrl+Enter 可「插话」：插入到当前回合；失败时有提示。

**CHAT-10 输入框**
- 支持：文件标签、粘贴图片、粘贴文件、**从资源管理器拖文件进来**、斜杠命令、语音输入、长文本粘贴自动转成附件。
- 图片作为图片内容发给模型；其它文件以路径标签交给代理自己读。
- 输入框左下角能切换工作模式（见 MODE），能选引擎/模型、工作目录、git worktree 模式。

**CHAT-11 斜杠命令**
- 内置命令 + 各引擎自带命令 + 技能命令都能在 `/` 菜单里找到，按当前引擎过滤，显示说明。
- 项目初始化方案以 `/init-名称` 出现（见 MEM-06）。

**CHAT-12 消息操作**
- 复制、编辑后重发、重新生成、选段引用（带行号）、书签。
- 用户能对任一条 AI 回复「重新生成」。

**CHAT-13 每轮改动与回退**
- 每一轮改了哪些文件都有记录；可以一键回退到这一轮之前（只回滚文件）。
- 在对比视图里可以**逐块撤回** AI 的某一处修改。

**CHAT-14 轮预算与失败回退**
- 设置里可开「每轮预算」：最多轮数 / 最多花费（美元）/ 最多 token。任一达到就在**回合中途**停止并提示原因（三个引擎都要能中途停，不是等回合结束）。
- 可配置失败回退模型链：模型报错时自动换下一个模型重试（只用于普通对话）。

**CHAT-15 上下文与用量显示**
- 状态栏显示上下文占用环（已用 / 上限 / 百分比、接近上限时警告），没有数据时显示空环而不是消失。
- 每轮显示耗时、token、花费。

**CHAT-16 会话管理**
- 多会话、多标签；会话可重命名、置顶、归档（含自动归档）、删除、搜索、分叉（复制一份从某处继续）。
- **侧聊 / 子对话**：另开一条旁支提问，不打断主对话。
- 会话右键：复制会话 id、挂载到当前对话（让当前对话读另一个会话的记录）。
- 会话标题自动生成（可配置用哪个模型）。

**CHAT-17 子代理面板**
- 能看到当前回合起的子代理：名字、状态、过程；子代理跑完不丢上下文。

**CHAT-18 代理之间通信**
- 代理之间可以互相发消息（通知，不等回复）和提问（要等回复）。
- 发出和收到的信件在**双方对话里都直接显示全文**（发信方显示「发给 / 向…提问 / 回信给」卡片，收信方显示来信卡片），并显示送达情况。

**CHAT-19 输出风格**
- 可选择/自定义输出风格，对 Claude 会话从下一轮起生效。

## 三、工作模式（MODE）

**MODE-01 六种内置模式**
- 默认、文献检索、文献精读、文献写作、文献评审、代码编辑；在输入框左下角切换，选中即用（不需要运行按钮）。
- 每种模式的提示词都能在设置里修改，并能「恢复默认」。

**MODE-02 两层提示**
- 「文件架构与读法」（东西在哪、怎么读、有什么规矩）每轮、每种模式都注入。
- 模式自己的流程提示只在选中该模式时注入。

**MODE-03 流程脚本**
- 模式配套的查库/检索/核对脚本随应用发布，落在数据目录；用户没改过的脚本随版本自动升级，改过的保持不动。

## 四、资料库（LIB）

> 统一名称是「资料库」。资料库是通用的资料管理（论文、教材、笔记、文档、幻灯、LaTeX、代码、图片……），不是只针对文献。

**LIB-01 分类**
- 三级分类：大类 → 类型 → 集合（分类），三级都能新建、重命名、删除、移动。
- 每一级都能写「给 AI 的提示词」，逐级叠加注入。
- 用户可以自建类型。

**LIB-02 条目**
- 支持：导入任意文件（PDF、Word、PPT、图片、代码……）、文件夹条目、单条笔记。
- 条目有引用信息（作者、年份、卷 / 期 / 页码、出版社、DOI、arXiv 号等），按 DOI / arXiv 号去重。
- 条目可以同时属于多个分类。

**LIB-03 关联**
- 条目之间可以建关联（一对多，可关联库外文件）；双方都看得到（「我关联了谁 / 谁关联了我」）。
- 引用一条条目时，它关联的条目自动一起挂上（一跳）。
- PDF 转出的 Markdown 和它的图片目录与原条目视为一个整体（一起显示、一起删除）。

**LIB-04 屏蔽规则**
- 可按任意层级节点或按文件类型屏蔽「给 AI 看的内容」，向下继承；屏蔽 PDF 时如果有转录 Markdown 就只给转录。

**LIB-05 回收站**
- 所有回收站合并成一个，固定在最底部。
- 从分类里移除条目时：只有它不再属于任何分类才进回收站。
- 回收站里**只删除、不还原**（彻底删除时展示连带的关联，让用户勾选）。

**LIB-06 检索与浏览**
- 能按关键词检索标题、摘要、来源、文件路径；库内全文检索在命令面板（Ctrl+K）的「文档」页签里。
- 左栏树状浏览；右栏预览（PDF、Markdown、图片、Office 文档）。

**LIB-07 转 Markdown**
- PDF 可转成 Markdown（MinerU 在线接口），供 AI 精读和引用。
- 没配置令牌时**跳过**并说明原因，不当作失败。

**LIB-08 文献检索与下载的分工**
- 检索与 PDF 下载由**外部 MCP 工具 + 内置浏览器**完成；Mcode 负责把结果导入资料库、归入分类、校验下载的确实是 PDF。
- 内置浏览器可配置学校/机构登录入口与代理前缀，借用已登录的机构账号下载；账号密码只存在浏览器里，不写进数据库。
- Mcode 本身不提供联网搜索 / 网页抓取类工具。
- 「文献导入」类流程**只手动触发**，不监听事件自动跑。

**LIB-09 模版**
- LaTeX、Word、PPT、代码、图片模版在资料库里统一管理（不是独立的「模版库」入口）。

**LIB-10 AI 使用资料库**
- 每轮给 AI 的是**清单（路径）**，AI 用文件工具自己读，不把全文塞进上下文。
- AI 有一组资料库工具（查分类、搜索、列条目、看关联、写笔记、建关联等），效果与用户在界面上操作一致。

## 五、编辑器与文档（EDIT）

**EDIT-01 文件树**
- 右栏文件树标出 AI 本轮新建/修改的文件；支持新建、重命名、移动、复制、删除、在资源管理器中打开。
- 单击预览、双击在中间栏打开。

**EDIT-02 代码编辑器**
- Monaco 编辑器，支持 30 多种语言；编辑 / 对比 / 预览三种视图。
- 磁盘上的文件被外部（包括 AI）改动时：没有本地未保存改动就自动刷新；有冲突就提示，不静默覆盖任一方。

**EDIT-03 Markdown**
- 所见即所得 / 预览 / 源码三档，默认所见即所得；没编辑不写盘。
- 长文滚动加载（看到哪里加载哪里附近）；预览里的相对路径图片正常显示；支持公式。

**EDIT-04 Office 文档**
- Word / Excel / PPT 在应用内直接编辑（OnlyOffice），改动直接存回原文件；Windows 上可在设置里一键安装/配置。

**EDIT-05 PDF**
- 应用内阅读 PDF；能划高亮并写回为 PDF 文件里真正的批注。

**EDIT-06 选段引用**
- 在聊天消息、文件预览、编辑器（含 Monaco）里选中一段，都能引用给**任意一个代理**（带文件与行号）。

**EDIT-07 行内 AI 改写**
- 在编辑器里选中一段，当场让 AI 改写，结果直接替换（可撤销）。

**EDIT-08 修订模式**
- 可开关。开着时，AI 对文件的修改先**不写入**，而是在编辑器里显示为红绿标记的「建议」，用户逐条接受/拒绝后才真正写入。

**EDIT-09 文件历史**
- 每个文件能查看以前的版本并回到某个版本，不依赖 git。

**EDIT-10 评论 / 批注给 AI**
- 能在文档里给某段写评论，评论可以交给 AI 处理（按评论改）。

## 六、开发工具（IDE）

**IDE-01 Git**
- 自动识别项目里的多个仓库；暂存、取消暂存、提交、推送、拉取、切换分支、查看历史与差异。
- AI 可以写提交信息、帮忙解决合并冲突。
- 会话可以在独立的 git worktree 里运行。

**IDE-02 终端**
- 多标签终端，中文不乱码；切换项目时后台终端不关闭；终端可嵌入到对话下方显示。
- 每个项目可存常用命令，一键执行。

**IDE-03 语言服务（LSP）**
- TypeScript、Python、Go、Java，在设置里一键安装；提供跳转定义、查找引用、实时报错。
- 语言服务起不来时，工具栏状态变红并显示原因。

**IDE-04 内置浏览器**
- 多标签；可切换桌面 / iPhone / Android 尺寸。
- 能点选网页元素发给 AI；AI 能自己操作浏览器（打开网页、点击、输入、截图）。

**IDE-05 守望**
- 能把一条命令绑定到会话上运行，命令结束后把结果交回该会话（唤醒模型继续）。

## 七、工作流（WF）

> **工作流 = 一种工作方式**（像「文献精读」那样），在输入框左下角选中后正常发消息即按图执行，没有「运行」按钮。
> 多代理协作（包括「开会」、多个评审交叉评审）**用工作流搭出来**，不另做一套会议系统；工作流需要的话可以加新的节点类型。

**WF-01 图模型与编辑**
- 节点 + 依赖边；分支的出路写在边上（名称、说明）。画布可拖拽编辑，节点检查器编辑参数。
- 校验：普通工作流有且只有一个主代理节点；自动化至少有一个触发器；不合法的图保存时给出明确错误。

**WF-02 节点类型**
- 主代理（跑在主对话里，用户看得见）、子代理（跑在自己的会话里）、对话节点（跑在主对话里的一轮）、
  岔路口（用户选或模型判）、条件判断（声明式 AND/OR，不调用模型）、命令、代码（Python / Node / Shell / PowerShell）、触发器。
- 插件可以注册自己的节点类型，第三方节点可以带自己的脚本。

**WF-03 调度**
- 就绪即派发，有并发上限（设置里可改）。
- 失败、跳过、未选中三种状态分开传播；命令非零退出码不算流程失败。
- 支持取消、回环（「再来一轮」只重跑环体）、「运行前先问我」。

**WF-04 变量**
- 节点有产出变量，下游用 `{{某步.某变量}}` 引用；自动化的触发载荷用 `{{trigger.*}}` 引用；引用不到时这一步明确失败并说明原因。

**WF-05 进度与结果**
- 画布上运行中的节点有实时进度（亮线、耗时逐秒走）。
- 对话里每步一张结果卡，同一步多轮时原地换成最新一版；卡上能看过程、产出、token 与花费。
- 看板面板列出各节点卡片与子代理。

**WF-06 断点续跑与重试**
- 应用或进程崩溃后，运行能从停下的地方接着跑；失败后能从失败那一步重试。
- 可以点任一节点，以它为起点接着跑（包括重启之后）。
- 工作流图在运行后被改过时，拒绝用旧状态续跑并说明原因；中断时可能已产生副作用的节点不自动重放，提示用户核对。
- 没有真正执行任何东西的节点（如分支选完）不应被当作「可能有副作用」而挡住重试。

**WF-07 与节点对话**
- 用户可以随时直接跟任一子代理节点说话（不只是失败后）；子代理跑完保留上下文，下次在同一对话里认回同一个会话。
- 子代理能把消息递给主代理（写进输入框草稿，由用户决定发不发）。
- 每个代理每轮都知道整条流程和自己所处的阶段。

**WF-08 代理档案**
- 可定义代理档案（指令、技能、引擎、能力），节点从档案创建；档案可挂记忆注入。

**WF-09 管理**
- 工作流列表：新建、复制、删除、导入、导出、设为默认、恢复默认。
- 导入的或 AI 修改过的工作流，在用户审查并启用之前不能运行。
- 工作流级「框架说明」会拼进每个节点的提示词。

## 八、自动化（AUTO）

> **自动化 = 后台自动跑**（像 cron / 文件监听），入口在设置 → 自动化，有「立刻运行一次」按钮。

**AUTO-01 触发器**
- 手动、定时（cron）、文件变化（带防抖）、事件（挂在钩子事件表上，如「条目入库」「PDF 下载完成」「一轮结束」）四种。
- 每个触发器可单独启用/关闭；关闭只挡自动触发，手动运行照跑。

**AUTO-02 运行与记录**
- 同一个自动化运行中时再次触发会跳过（防重入）。
- 仪表盘按触发器显示：是否已挂上 / 已关闭 / 没挂上（坏了）、运行状态、最近一次、报错；有运行历史。
- 应用没开时错过的定时会记录为「错过」。

**AUTO-03 内置自动化示例**
- 提供「新条目入库后自动下载」「PDF 到位后自动转 Markdown」等示例，可删除、可修改。

## 九、钩子、技能、MCP、插件（EXT）

**EXT-01 钩子**
- 在事件发生时运行用户自己的命令。事件覆盖一轮的生命周期：发消息、工具调用、工具结果、等待审批、审批/提问被回答、提问、计划待批、待办变化、子代理变化、改动文件、一轮未完成、一轮结束、上下文压缩、出错、上游重试、工作流节点完成、条目入库、PDF 下载完成。
- 可按工具名/文件路径匹配；每次执行有记录（标明是本次启动以来的记录）。

**EXT-02 技能**
- 管理 SKILL.md 技能：全局、项目级、跨项目总览三个页签，自带编辑器；技能可作为斜杠命令使用，可预设。

**EXT-03 MCP 服务器管理**
- 添加/编辑/删除/启停 MCP 服务器（stdio / http / sse），可指定给哪些引擎用；http 类支持 OAuth。
- 能检测服务器是否连得上（命令不存在、起不来时要告诉用户）。

**EXT-04 插件（大模型插件）**
- 支持安装大模型插件：一个包里可以带技能、MCP 服务器、工作流节点类型；全局安装/启用，工作流可逐轮指定。
- 不做类似 DeepSeek Harness 那种「一切皆插件」的应用插件内核；应用界面的自定义由「自定义界面」（EXT-05）负责。

**EXT-05 自定义界面**
- 主界面上的挂载位：资料库四级右键（条目 / 分类 / 小类 / 大类）、文件右键、消息右键、选中文字、会话右键、右栏页签、主页面与右栏之间的竖向工具栏。
- 每个挂载位可以：显示/隐藏、排序内置项；添加自定义项（名字 + 图标 + 显示条件 + 动作）。
- 动作是声明式的：打开视图（Markdown 模板）、发给对话（提示词模板）、复制文本、运行自动化、打开文件、切到右栏某页签。
- 可以添加自定义面板（HTML，在严格隔离的沙箱里运行，不能联网、不能执行任意代码）。
- 管理类菜单项（重命名、移动、删除、新建分类等）固定，不可隐藏。

**EXT-06 Mcode 自身的工具（给本地三个引擎用）**
- 三个本地引擎可以通过工具操作 Mcode 自己的功能：一个通用的「先列出、再调用」通道覆盖全部功能，加上常用功能的专用工具。
- 危险操作每次都要用户批准，不允许「总是允许」；API Key 与令牌不返回给模型。

## 十、记忆与上下文（MEM）

**MEM-01 记忆库**
- 跨会话记住规则、偏好、经验、决定等（分类目存为可直接编辑的 Markdown 文件），分全局与项目两级。

**MEM-02 注入**
- 每轮按相关性检索记忆注入给模型；能预览「这一轮会注入什么」。

**MEM-03 模型写记忆**
- 模型能通过工具写入/检索/遗忘记忆；工具说明要求不记敏感信息。

**MEM-04 维护**
- 能查看、编辑、删除记忆；「整理记忆」找出过期或重复的条目，由用户确认后清理（不自动删除）。

**MEM-05 导入导出**
- 记忆可以导出、导入（迁移到另一台机器）。

**MEM-06 项目初始化**
- 在设置 → 记忆与上下文 →「项目初始化」页签里管理初始化方案（自定义要生成的文件 / 目录 / 项目记忆）；每个方案成为 `/init-名称` 命令。
- 执行时：预览后确认、不覆盖已有文件、作用于会话当前项目（含 worktree）。

## 十一、手机远程（MOB）

**MOB-01 连接方式**
- 局域网内扫码配对。
- 外网：用户自己运行 cloudflared（快速隧道或自有域名），Mcode 显示本地地址和需要的配置；Mcode 不托管隧道令牌。
- 手机远程连接与设置里的「远程控制（MCP）」开关**互相独立**，不需要打开那个开关。

**MOB-02 登录**
- 手机端用账号 + 密码登录；设备可在电脑上查看与吊销。

**MOB-03 手机上能做的事**
- 看会话列表与对话、搜索会话、发消息、批准/拒绝操作、回答提问、看文件、看 Git 状态并提交/推送；部分设置（语言、强调色、快捷命令等）在电脑和手机之间同步。

**MOB-04 连接手机对话框**
- 固定高度，内容在内部滚动。

## 十二、对外 MCP 端点（PUB）

**PUB-01 公网 MCP**
- 可以开一个公网 MCP 端点（链接里带密钥），让网页版 AI（如 ChatGPT 网页版）调用 Mcode 的工具；可配置多个项目。

**PUB-02 开放的能力**
- 资料库：**只读**浏览与检索。
- 本地技能与工具：读写项目文件、执行命令、进程、SSH 与远程任务、读文档/图片等。
- 根据使用者类型给出对应的使用说明。

**PUB-03 不开放的能力**
- 不提供工作流 / 自动化工具；不暴露会话记录与代理信件工具；不返回任何密钥。
- 写文件、执行命令等操作需要用户在 Mcode 里确认。

## 十三、设置与系统（SYS）

**SYS-01 设置页**
- 至少包含：通用、外观、自定义模型、引擎/运行时、插件、技能、工作流、自动化、钩子、MCP、记忆与上下文、语音、快捷键、手势、通知、资料库类型、自定义界面、机构访问、Git、终端、浏览器、语言服务、运行策略（预算/回退）、监控、用量、关于。

**SYS-02 外观**
- 主题、强调色、字号可调；手绘风格等主题样式；修改即时生效。

**SYS-03 快捷键与手势**
- 快捷键可自定义（录制），冲突时提示；鼠标手势（按住右键拖动）可录制并绑定到与快捷键同一套命令。

**SYS-04 通知**
- 需要审批/提问/计划待批、回合完成、出错、后台任务完成时通知，可按类别开关；应用失焦时用系统通知，聚焦时用应用内提示；未读事件在会话列表和标签栏显示角标；可开提示音。

**SYS-05 语音输入**
- 使用本地识别模型，不上传音频；可在设置里下载/切换模型。

**SYS-06 监控与用量**
- 监控页：后台运行（工作流、自动化）的概览与历史。
- 用量页：统计 token 与花费（按时间、模型等维度），每轮的用量记录重启后仍在。

**SYS-07 数据目录**
- 会话、资料库、模版、工作流、记忆都放在同一个数据目录下，可在设置里查看与迁移。

**SYS-08 更新**
- 应用自动检查更新，也可在「关于」里手动检查；有新版时提示下载安装。

**SYS-09 首页**
- 没有打开会话时显示「开始一件事」：接着聊、用工作流开始、最近加入的资料、正在守着的自动化；没内容的块不显示。

**SYS-10 命令面板**
- Ctrl+K 打开，能搜索会话、文件、资料库文档、命令。

**SYS-11 安装包**
- Windows：按用户安装的 `.exe`，不需要管理员权限；同时提供 macOS `.dmg`（不作为检查重点）。
